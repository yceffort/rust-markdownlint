> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 규칙 2개(MD047, MD018)만 포함하되 CLI, 설정, 파서, 규칙 엔진, fix, 테스트 하네스가 모두 연결된 실행 가능한 `rust-markdownlint` 바이너리를 만든다.

  pub type TokenId = usize;
  pub struct Token { pub kind: markdown::event::Name, pub start_line: usize, pub start_column: usize,
                     pub end_line: usize, pub end_column: usize, pub text: String,

#[test]
fn atx_heading_tokens() {
    let tree = parse("# Hello\n");
    let heads = tree.filter_by_types(&[Name::HeadingAtx]);
    assert_eq!(heads.len(), 1);
    let h = tree.get(heads[0]);
    assert_eq!((h.start_line, h.start_column, h.end_line, h.end_column), (1, 1, 1, 8));
    let seq = tree.descendants_by_type(heads[0], &[Name::HeadingAtxSequence]);
    assert_eq!(tree.get(seq[0]).text, "#");
}

#[test]
fn column_is_codepoint_based() {
    let tree = parse("# 한글\n");
    let h = tree.get(tree.filter_by_types(&[Name::HeadingAtx])[0]);
    assert_eq!(h.end_column, 5);
}
